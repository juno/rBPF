# rbpf Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** cBPF(classic BPF)の命令列とパケットを受け取り、Linuxと同じ返り値を返すRuby製シミュレーターを作る。

**Architecture:** `Rbpf.run(prog, packet)` が verifier で命令列を検査してから、`VM` が A/X/`M[16]`/pc を持つ実行ループで命令を1つずつ実行する。オペコードは `linux/filter.h` と同じ数値の定数(`Rbpf::Op`)で持つ。

**Tech Stack:** Ruby 標準ライブラリのみ、Minitest、Rake(Ruby同梱)。外部gemなし。

**Spec:** `docs/superpowers/specs/2026-09-29-rbpf-design.md`

## Global Constraints

- eBPFは対象外。`SKF_AD_*` と負オフセットは実装しない
- オペコードは `linux/filter.h` と同じ数値
- A, X, `M[0..15]` は32bit unsigned(演算ごとに `& 0xFFFFFFFF`)
- パケット読み出しはビッグエンディアン。範囲外の読み出しと X=0 の `div/mod` は例外にせず返り値0
- 命令数の上限は4096
- `lsh/rsh` のシフト量が32以上なら結果0
- テスト名は英語。実装中はテストを変更しない(TDD)
- コミットメッセージは日本語、末尾に `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`

## Review Focus

1. `ld [x+k]` で `X+k` が32bitを超えたら折り返して読む(Task 3)
2. `ld [k]` で k が巨大(`0xFFFFFFFF`)でも例外にならず返り値0(Task 3)
3. `jgt/jge` は符号なし比較(最上位ビットが立つ値でも大小が逆転しない)(Task 5)
4. ALU結果は常に32bit(`sub` の負値、`neg`、`lsh` のオーバーフロー)(Task 4)
5. `ja` の k が巨大(`0xFFFFFFFF`)でも verifier が不正と判定する(Task 2)

```ruby
    JA = 0x00; JEQ = 0x10; JGT = 0x20; JGE = 0x30; JSET = 0x40
    # ret value source
    RET_K = 0x00; RET_X = 0x10; RET_A = 0x18
    # misc op

  end
end
```

`lib/rbpf/verifier.rb`:

```ruby
module Rbpf
  class InvalidProgram < StandardError; end

  module Verifier
    MAX_INSNS = 4096
    MEMWORDS = 16

    LD_CODES = [Op::W, Op::H, Op::B].product([Op::ABS, Op::IND]).map { |s, m| Op::LD | s | m } +
               [Op::LD | Op::W | Op::IMM, Op::LD | Op::W | Op::LEN, Op::LD | Op::W | Op::MEM]
    LDX_CODES = [Op::LDX | Op::W | Op::IMM, Op::LDX | Op::W | Op::LEN,
                 Op::LDX | Op::W | Op::MEM, Op::LDX | Op::B | Op::MSH]
    ALU_CODES = [Op::ADD, Op::SUB, Op::MUL, Op::DIV, Op::OR, Op::AND,
                 Op::LSH, Op::RSH, Op::MOD, Op::XOR]
                .product([Op::K, Op::X]).map { |o, s| Op::ALU | o | s } + [Op::ALU | Op::NEG]
    JMP_COND_CODES = [Op::JEQ, Op::JGT, Op::JGE, Op::JSET]
                     .product([Op::K, Op::X]).map { |o, s| Op::JMP | o | s }
    RET_CODES = [Op::RET | Op::RET_K, Op::RET | Op::RET_X, Op::RET | Op::RET_A]
    MISC_CODES = [Op::MISC | Op::TAX, Op::MISC | Op::TXA]

    def self.verify!(prog)
      bad(nil, "empty program") if prog.empty?
      bad(nil, "program too long") if prog.size > MAX_INSNS
      prog.each_with_index { |insn, pc| check(insn, pc, prog.size) }
      bad(prog.size - 1, "last instruction must be ret") unless prog.last.code & 0x07 == Op::RET
      nil
    end

    def self.check(insn, pc, n)
      code = insn.code
      case code
      when Op::LD | Op::W | Op::MEM, Op::LDX | Op::W | Op::MEM, Op::ST, Op::STX
        bad(pc, "scratch index out of range") unless insn.k < MEMWORDS
      when Op::ALU | Op::DIV | Op::K, Op::ALU | Op::MOD | Op::K
        bad(pc, "division by zero") if insn.k == 0
      when Op::JMP | Op::JA
        bad(pc, "jump out of range") unless pc + 1 + insn.k < n
      when *JMP_COND_CODES
        bad(pc, "jump out of range") unless pc + 1 + insn.jt < n && pc + 1 + insn.jf < n
      when *(LD_CODES + LDX_CODES + ALU_CODES + RET_CODES + MISC_CODES)
        nil
      else
        bad(pc, "unknown opcode 0x#{code.to_s(16)}")
      end
    end

    def self.bad(pc, msg)
      raise InvalidProgram, pc ? "insn #{pc}: #{msg}" : msg
    end
  end
end
```

`lib/rbpf/vm.rb`:

```ruby
module Rbpf
  class VM
    MASK = 0xFFFFFFFF
    SIZES = { Op::W => ["N", 4], Op::H => ["n", 2], Op::B => ["C", 1] }.freeze

    def initialize(prog, packet)
      @prog = prog
      @pkt = packet.b
      @a = 0
      @x = 0
      @m = Array.new(Verifier::MEMWORDS, 0)
    end

    def run
      pc = 0
      catch(:ret) do
        loop do
          insn = @prog[pc]
          pc += 1
          case insn.code & 0x07
          when Op::LD, Op::LDX then load(insn)
          when Op::ST then @m[insn.k] = @a
          when Op::STX then @m[insn.k] = @x
          when Op::RET then throw :ret, ret_value(insn)
          when Op::MISC then insn.code == (Op::MISC | Op::TAX) ? @x = @a : @a = @x
          end
        end
      end
    end

    private

    def load(insn)
      size = insn.code & 0x18
      value = case insn.code & 0xe0
              when Op::IMM then insn.k
              when Op::LEN then @pkt.bytesize
              when Op::MEM then @m[insn.k]
              when Op::ABS then read(insn.k, size)
              when Op::IND then read((@x + insn.k) & MASK, size)
              when Op::MSH then 4 * (read(insn.k, Op::B) & 0xf)
              end
      (insn.code & 0x07) == Op::LD ? @a = value : @x = value
    end

    # 範囲外は例外にせず、プログラム全体を返り値0で終了する(カーネル準拠)
    def read(offset, size)
      fmt, len = SIZES.fetch(size)
      throw :ret, 0 if offset + len > @pkt.bytesize
      @pkt.byteslice(offset, len).unpack1(fmt)
    end

    def ret_value(insn)
      case insn.code & 0x18
      when Op::RET_K then insn.k
      when Op::RET_X then @x
      else @a
      end
    end
  end
end
```

```ruby
    def alu(insn)
      src = (insn.code & Op::X) == Op::X ? @x : insn.k
      result = case insn.code & 0xf0
               when Op::ADD then @a + src
               when Op::SUB then @a - src
               when Op::MUL then @a * src
               when Op::DIV then (throw :ret, 0 if src == 0; @a / src)
               when Op::MOD then (throw :ret, 0 if src == 0; @a % src)
               when Op::OR then @a | src
               when Op::AND then @a & src
               when Op::XOR then @a ^ src
               when Op::LSH then src >= 32 ? 0 : @a << src
               when Op::RSH then src >= 32 ? 0 : @a >> src
               when Op::NEG then -@a
               end
      @a = result & MASK
    end
```

```ruby
    def jump(insn, pc)
      op = insn.code & 0xf0
      return pc + insn.k if op == Op::JA

      src = (insn.code & Op::X) == Op::X ? @x : insn.k
      taken = case op
              when Op::JEQ then @a == src
              when Op::JGT then @a > src
              when Op::JGE then @a >= src
              when Op::JSET then (@a & src) != 0
              end
      pc + (taken ? insn.jt : insn.jf)
    end
```

```ruby
require "test_helper"

class TcpdumpFilterTest < Minitest::Test
  ACCEPT = 262144

  PROG = [
    ins(Op::LD | Op::H | Op::ABS, 12),                 # 0: ethertype
    ins(Op::JMP | Op::JEQ | Op::K, 0x800, 0, 8),       # 1: IPv4 でなければ 10 へ
    ins(Op::LD | Op::B | Op::ABS, 23),                 # 2: protocol
    ins(Op::JMP | Op::JEQ | Op::K, 6, 0, 6),           # 3: TCP でなければ 10 へ
    ins(Op::LD | Op::H | Op::ABS, 20),                 # 4: flags/fragment offset
    ins(Op::JMP | Op::JSET | Op::K, 0x1fff, 4, 0),     # 5: フラグメントなら 10 へ
    ins(Op::LDX | Op::B | Op::MSH, 14),                # 6: X = IHL * 4
    ins(Op::LD | Op::H | Op::IND, 16),                 # 7: TCP dst port
    ins(Op::JMP | Op::JEQ | Op::K, 80, 0, 1),          # 8: 80 でなければ 10 へ
    ret_k(ACCEPT),                                     # 9
    ret_k(0)                                           # 10
  ].freeze

  def packet(ethertype: 0x0800, proto: 6, frag: 0, ihl: 5, dport: 80)
    eth = ("\0" * 12) + [ethertype].pack("n")
    ip = [0x40 | ihl, 0, 40, 0, frag, 64, proto, 0, 0, 0].pack("CCnnnCCnNN")
    ip += "\0" * ((ihl - 5) * 4)
    tcp = [12345, dport].pack("nn") + ("\0" * 16)
    (eth + ip + tcp).b
  end

  def test_accepts_tcp_port_80
    assert_equal ACCEPT, Rbpf.run(PROG, packet)
  end

  def test_accepts_with_ip_options
    assert_equal ACCEPT, Rbpf.run(PROG, packet(ihl: 6))
  end

  def test_rejects_other_port
    assert_equal 0, Rbpf.run(PROG, packet(dport: 22))
  end

  def test_rejects_non_ipv4
    assert_equal 0, Rbpf.run(PROG, packet(ethertype: 0x0806))
  end

  def test_rejects_udp
    assert_equal 0, Rbpf.run(PROG, packet(proto: 17))
  end

  def test_rejects_fragment
    assert_equal 0, Rbpf.run(PROG, packet(frag: 0x0001))
  end

  def test_rejects_truncated_packet
    assert_equal 0, Rbpf.run(PROG, packet[0, 20])
  end
end
```
